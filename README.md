# EasyVisa – Work Visa Approval Prediction

## 📌 Problem Statement

The increasing number of visa applications makes manual processing difficult.
This project uses Machine Learning to predict whether a visa application will be **Certified or Denied**.

---

## ⚙️ Tech Stack

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn
* SMOTE (Imbalanced Data Handling)

---

## 🔍 Approach

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Handling class imbalance using SMOTE
* Model building:

  * Decision Tree
  * Random Forest
  * AdaBoost
  * Gradient Boosting
* Hyperparameter tuning
* Model evaluation using Accuracy, Precision, Recall, F1-score

---

## 📊 Results

* Ensemble models (AdaBoost & Gradient Boosting) performed best
* Successfully handled imbalanced dataset
* Achieved strong classification performance

---

## 💡 Key Insights

* Applicants with prior job experience have higher approval chances
* Higher education increases approval probability
* Wage and region influence visa decisions
